# LeadBridge AI — مهدیار هوش‌افزا

سیستم **مولتی‌ایجنت جذب و تحویل لید** برای برند مهدیار هوش‌افزا. کسب‌وکارهای هدف را پیدا می‌کند، راه‌های ارتباط مجازی‌شان را استخراج می‌کند، درد اصلی‌شان را تحلیل و امتیازدهی می‌کند، و برای لیدهای مناسب یک **پیام عمیقاً شخصی‌سازی‌شده** — بر پایه‌ی هویت برند مهدیار — آماده می‌کند تا پس از **تأیید انسانی** ارسال شود.

> استک: **Next.js 14 + Vercel AI SDK + OpenRouter + Supabase** · TypeScript · Tailwind.
> این پروژه بازطراحیِ یک سیستم مولتی‌ایجنت است؛ کد نسخه‌ی قبلی (بلاگ) در `_archive/blog/` نگه داشته شده.

---

## معماری (خلاصه)

هر جزء یا **Agent** (LLM: تحلیل/قضاوت) است یا **Service** (کد قطعی: محاسبه/قاعده). ارکستریتور خودش کد قطعی است، نه LLM.

```
کشف لید (Google Maps) → استخراج کانال‌های ارتباط → اعتبارسنجی/حذف تکراری
  → تحلیل (درد اصلی) → امتیازدهی (۷ معیار وزنی، آستانه ۷۰)
  → انتخاب خدمت (از ۷ خدمت مهدیار) → انتخاب نمونه‌کار
  → نوشتن پیام ⇄ نقد پیام (≤۲ دور) → Policy Guard
  → پیش‌نویس + تأیید انسانی → ارسال → تحویل (Handover)
  → درس‌گیری خودبهبودی
```

**اصول کلیدی:** فقط APIهای رسمی (Google Places New + Instagram Graph business_discovery)؛ بدون اسکرپ نامحدود و بدون دایرکت سرد انبوه؛ پیام همیشه پیش‌نویس + تأیید انسانی؛ بدون قیمت/تخفیف/قرارداد؛ شخصی‌سازی مبتنی بر درد واقعی هر بیزینس.

## ساختار

```
src/lib/
├── brand.ts        ← هویت برند مهدیار: ۷ خدمت، پرسوناها، لحن، کلمات مجاز/ممنوع، نمونه‌کارها
├── config.ts       ← بازارهای هدف (ICP)، وزن‌های امتیاز، روبریک نقد، سقف‌ها، اولویت کانال
├── ai.ts           ← هسته: OpenRouter + runAgentJSON/Text (اعتبارسنجی Zod + retry)
├── store/          ← لایه‌ی CRM (الگوی Adapter: Supabase یا حافظه)
├── integrations/   ← Google Places · Instagram · استخراج کانال‌ها  (فاز ۲)
└── agents/         ← ایجنت‌ها و سرویس‌های قطعی + ارکستریتور  (فازهای ۳–۵)
supabase/schema.sql ← اسکیمای کامل CRM + seed نمونه‌کارها
```

## راه‌اندازی

```bash
npm install
cp .env.local.example .env.local   # مقادیر را پر کنید
npm run dev                        # http://localhost:3000
```

برای ذخیره‌سازی دائمی، `supabase/schema.sql` را در SQL Editor پروژه‌ی Supabase اجرا کنید. متغیرهای محیطی لازم در `.env.local.example` توضیح داده شده‌اند.

## وضعیت ساخت (فازبندی)

- ✅ **فاز ۱ — زیرساخت + برند + داده** (store/CRM، schema، brand، config).
- ⏳ فاز ۲ — کشف لید (Google Maps + Instagram) + استخراج کانال‌ها + داشبورد لیدها.
- ⏳ فاز ۳ — تحلیل + امتیاز + انتخاب خدمت/نمونه‌کار.
- ⏳ فاز ۴ — تولید پیام + نقد + تأیید انسانی.
- ⏳ فاز ۵ — تحویل + خودبهبودی + ارسال نیمه‌خودکار.
